------------------------------------------------------------
4. OpenCV video codec note
------------------------------------------------------------

OpenCV normally downloads FFmpeg libraries for video I/O. This
application performs no video operations, and the build script
removes opencv_videoio_ffmpeg500_64.dll from the packaged output.
No FFmpeg code is distributed with this project.
